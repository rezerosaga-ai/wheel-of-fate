3. **الـ baseline الاحتياطي:** commit `4c5777d3` لأي تراجع مستقبلي.
4. **قاعدة البيانات لا تُسترد** — أي تعديل schema يمر بمراجعة migration غير مدمرة.
5. **المحتوى المخصص (أسئلة عبدو×أنفال) هو جوهر المنتج** — أي APIs خارجية طبقة إضافية فقط.

### الأولوية 2 — الرسائل الصوتية (Voice Messages)

الميزة الوحيدة المسجلة رسميًا كـNOT_IMPLEMENTED بعد كشف harness (audio_probe = NOT_RETESTED لأن العنصر غير موجود أصلًا):

- تسجيل رسالة صوتية عبر Web Audio API / MediaRecorder (زر مايكروفون في الدردشة).
- تخزين المقاطع في S3 (يتطلب ترقية المشروع إلى web-db-user أو الاعتماد على Vercel Blob/Nebula لأن Vercel حاليًا هو المستضيف).
- مشغل صوتي مدمج في ChatPanel مع موجة صوتية ومرات تشغيل.
- **مخاطرها:** تخزين الملفات، صلاحيات الميكروفون على TWA/Android، حجم الغرفة. تحتاج تصميم schema + API قبل الكود.

### الأولوية 3 — توسيع Conflict Room

النسخة الحالية تعمل (loop كامل موثق: loveCounter 5→6)، والتوسيع المقترح:

- **Challenge (التحدي):** مسجل في دورة اللعبة (`challenge_answer`) لكن غير مكتمل التفعيل — إكمال تدفق التحدي الرسمي بدل الاكتفاء بالأدوات.
- **أدوات إضافية:** 💌 الرسالة السرية مسجلة كأداة في README لكن تنفيذها محدود — تعميقها.
- **محتوى عاطفي:** بطاقات حوار إرشادية إضافية داخل Conflict Room (أسئلة تفاهم، تمارين إنصات).

### الأولوية 4 — المحتوى الخارجي (طبقة إضافية)

كما اقترح تقرير public-apis: JokeAPI (نكت عربية/عالمية لفئة الضحك)، aztro (الحظ اليومي)، YesNo — عبر `api/external/` **دون إدخالها في المسار الأساسي**.

### الأولوية 5 — بنود الاحتياط قبل الحملة التسويقية (إلزامية قبل أي push)

| البند | لماذا إلزامي |
